### 2. 前端测试与路由底座

- 接入 React Router DOM、Vitest、Testing Library、user-event、jsdom 和 Playwright。
- 建立集中式路由与权限元数据：根路径规范化到 `/overview`，允许路径支持刷新、前进、后退和直接访问。
- 权限不足进入 403，未知路径和冻结路径进入 404；导航入口与路由守卫使用同一权限定义。
- 桌面 1280x720 和移动 390x844 的生产预览路由场景已完成验证。

### 3. Fail-closed 隔离测试栈

- 新增 `compose.test.yaml` 与 `scripts/test-backend.ps1`，使用独立 Compose 项目 `supplier-risk-frontend-gap-test`。
- 测试数据库固定为 `supplier_risk_test`；数据库名不满足精确名称和 `_test` 后缀时，在任何清理操作前拒绝执行。
- PostgreSQL 数据目录使用 tmpfs；测试结束后删除专用容器、网络和临时资源，不复用业务数据库或生产凭据。
- 隔离 seed 提供管理员、低权限用户、25 家以上供应商及 current/expired 风险提醒。

### 4. 供应商服务端列表契约

- `q` 支持供应商编码、法人名称、注册编号、别名、产品名称和 JSONB 产品关键词搜索。
- 增加 `enabled` 与 `has_current_alert` 过滤，按 `supplier_code ASC, id ASC` 稳定分页。
- 列表返回最强有效当前风险等级与分值；expired 或已过期提醒不计入当前风险。
- 查询使用排名子查询和关系预加载，避免分页重复、遗漏和 N+1。

### 5. 本人改密与管理员重置拆分

- 旧 `/users/{user_id}/password` 仅允许本人调用，并继续强制校验旧密码。
- 新增 `/users/{user_id}/password-reset`，只允许拥有 `user_manage` 的管理员重置他人密码，请求不接受占位 `old_password`。
- 管理员不能通过重置接口修改自己的密码；弱密码返回 422，目标不存在返回 404，缺少权限或 CSRF 返回 403。
- 密码更新、目标用户全部会话撤销和安全审计在同一事务中提交；管理员自身会话不受影响。
- 显式拒绝 UTF-8 编码超过 bcrypt 72 字节边界的密码，避免多字节密码被截断；本人/创建契约保持 400，管理员重置保持 422。
- 认证模块按职责拆分为权限矩阵、密码策略、令牌派生和用户管理路由，既有 `app.auth.security` 公共导入保持兼容。
